# English lessons

1. Put the Craig recording in `sessions\<DD-MM-YY>\`.
2. **Transcribe Folder.bat** → audio to text.
3. **Analyze Lesson.bat** → `output\` with ~10 tutor phrases + ~10 of your mistakes.
   Already-learned words (`..\learned.json`) are skipped. Add `-Force` to redo.

Drag the folder onto the `.bat`, or double-click and pick it.

`One Click Transcribe.bat` is the old version — ignore it.

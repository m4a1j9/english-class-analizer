Everything listed here is excluded from future analysis runs. `Analyze Lesson.ps1`
injects this file into both prompts as a blocklist, so neither the tutor-phrases nor
the learner-corrections output will raise these again — including near-duplicates that

**How to use it:** after you review a lesson's output by hand, move the items you have
actually absorbed into the lists below. Keep it short and honest. An item parked here
too early means you stop being reminded of a mistake you still make; leaving a genuinely
learned item out means you burn one of the ~10 phrase slots on it again next lesson.

Lines starting with `#` are ignored, so headings and comments are free. One item per
bullet; the wording does not need to be exact — the model matches on meaning.

## Corrections already covered

These came out of the 2026-08-21 lesson and were reviewed. Delete any you are not
confident about yet.

- **work around → work on** — *work around* means to avoid or bypass, not to improve
- **allocate a variable → declare a variable** — allocate is about memory
- **verbally → verbosely** — verbally means out loud
- **behave → decide** — "we will behave based on our goals"
- **in this major → in this field** — major is a university subject, not an industry
- **is the actual thing → is the way to go**
- **go out of script → go off script**
- **providing the question with a different paraphrase → rephrasing the question**
- **missing the meaning → not quite sure I follow** (asking for clarification)
- **this one uses → this one is used** — missing passive when explaining a mechanism
- **in the actual world → in the real world**
- **agenda → syllabus / course outline** — an agenda is one meeting's item list
- **figured braces → curly braces**, **squared braces → square brackets**,
  **round bracers → parentheses**
- **on the flight → on the fly**
- **script based language → scripting language**
- **visited a lot of movies → saw a lot of movies**
